# Reporting security issues

Please report suspected vulnerabilities privately to the
[AWS Vulnerability Disclosure Program](https://hackerone.com/aws_vdp) or email
[aws-security@amazon.com](mailto:aws-security@amazon.com).

Do not include vulnerabilities, credentials, or sensitive customer data in
GitHub issues or pull requests.

This reporting guidance is adapted from the
[AWS Deadline Cloud organization security policy](https://github.com/aws-deadline/.github/blob/mainline/SECURITY.md).
That policy also provides the shared release verification keys.
